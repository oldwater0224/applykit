# 화면 명세서 — 홈 화면 스타트업 뉴스 섹션

> 대상: `src/app/page.tsx` 홈 화면
> 연관: `기능명세서-스타트업뉴스-v2.md`

---

## 1. 위치

홈 화면의 **"투자 라운드별 현황" marquee 섹션 바로 위**에 삽입한다.
기존 레이아웃 순서: 헤더 → 메인 통계 바 → **[뉴스 섹션]** → 라운드별 카드(marquee) → 2열 그리드

---

## 2. 데이터

| 항목 | 값 |
|---|---|
| 데이터 소스 | `getRecentNews(35)` 서버 액션 |
| 총 풀 | 35건 |
| 한 화면 표시 | 6건 |
| 교체 주기 | 7초 |
| 교체 방식 | 풀에서 랜덤 6건 선택 (이전 세트와 중복 허용, 매 교체마다 새 랜덤) |
| 데이터 없을 때 | 섹션 전체 미표시 (`null` 반환 시 렌더링 안 함) |

---

## 3. 디자인

### 3-1. 색상

| 요소 | 값 | 비고 |
|---|---|---|
| 섹션 배경 | `var(--navy-900)` (`#0f172a`) | 홈 페이지 배경과 동일 |
| 카드 배경 | `var(--navy-800)` (`#1a2340`) | 기존 카드 배경 톤과 통일 |
| 카드 보더 | `var(--navy-700)` (`#263354`) | |
| 제목 텍스트 | `#fff` | |
| 요약 텍스트 | `var(--gray-400)` (`#94a3b8`) | |
| 언론사·날짜 | `var(--gray-500)` (`#64748b`) | |
| 섹션 제목 | `#fff`, 13px, font-semibold | 기존 섹션 제목 스타일 동일 |
| 호버 보더 | `var(--brand-500)` (`#3b82f6`) | |

### 3-2. 카드 레이아웃

```
┌─────────────────────────────────┐
│ 뉴스 제목 (1줄, 말줄임)         │
│ 요약 (2줄, 말줄임)              │
│ 플래텀 · 2026.09.14            │
└─────────────────────────────────┘
```

- 제목: 14px, font-semibold, white, 1줄 말줄임 (`line-clamp-1`)
- 요약: 12px, `var(--gray-400)`, 2줄 말줄임 (`line-clamp-2`)
- 메타(언론사·날짜): 11px, `var(--gray-500)`, 하단 고정
- 카드 높이: 고정하지 않되 `min-h`로 일관성 유지
- 패딩: `px-4 py-3`
- 라운드 뱃지: `round_name`이 있으면 제목 왼쪽에 작은 도트+텍스트로 표시
- 클릭: `<a href={url} target="_blank" rel="noopener noreferrer">` — 뉴스 원문으로 이동

### 3-3. 그리드

| 브레이크포인트 | 컬럼 수 | 카드 간격 |
|---|---|---|
| `lg` (≥1024px) | 3열 2행 (3×2 = 6) | `gap-3` |
| `md` (≥768px) | 2열 3행 (2×3 = 6) | `gap-3` |
| `sm` / 모바일 (<768px) | 1열 세로 스크롤 (6개 세로 나열) | `gap-2` |

### 3-4. 전환 애니메이션

- 교체 시 `opacity` 페이드: 0.3초 fade-out → 데이터 교체 → 0.3초 fade-in
- CSS transition: `transition-opacity duration-300`

---

## 4. 반응형 상세

### 모바일 (< 768px)
- 카드 1열 세로 배치, 6개 모두 표시
- 제목 font-size: 13px
- 요약 1줄 말줄임으로 축소 (`line-clamp-1`)
- 섹션 좌우 패딩: 페이지 패딩(`px-4`)과 동일
- 카드 높이 최소화하여 스크롤 부담 줄임

### 태블릿 (768px ~ 1023px)
- 2열 그리드
- 제목/요약 데스크톱과 동일

### 데스크톱 (≥ 1024px)
- 3열 그리드, 2행
- 최대 너비 `var(--max-width)` (1280px) 준수

---

## 5. 인터랙션

| 동작 | 처리 |
|---|---|
| 카드 호버 | 보더 색상 `var(--brand-500)`, 약간의 `translateY(-1px)` |
| 카드 클릭 | 원문 URL로 새 탭 열기 (`target="_blank"`) |
| 자동 교체 | 7초마다 랜덤 6건, 탭이 비활성이면 일시정지 (`document.hidden`) |
| 마우스 호버 시 | 자동 교체 일시정지 (marquee와 동일 패턴) |

---

## 6. 컴포넌트 구조

```
src/app/components/home/
  NewsSection.tsx     — 서버 컴포넌트 (데이터 fetch)
  NewsRotator.tsx     — 클라이언트 컴포넌트 (로테이션 로직 + 렌더링)
```

- `NewsSection`: `getRecentNews(35)` 호출 → 데이터가 있으면 `NewsRotator`에 전달
- `NewsRotator`: `"use client"`, `useState`/`useEffect`로 7초 인터벌, 랜덤 선택
